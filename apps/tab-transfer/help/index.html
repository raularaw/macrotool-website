Tab Transfer setup guide

Everything you need to install Tab Transfer, set up your rules and automate your sheet.

1. Install Tab Transfer

  1. Open the Tab Transfer listing on the Google Workspace Marketplace and click Install. (The listing link will appear on the Tab Transfer page once it's published.)
  2. Choose the Google account you use for Sheets.
  3. Review the permissions and click Allow. Each permission is explained on the Tab Transfer page.

Using Google Workspace at work or school? Your administrator may need to allow the add-on, or can install it for your whole organisation from the Admin console.

2. Open it in a spreadsheet

Open any Google Sheets file you can edit and go to:

Extensions → Tab Transfer → Open Tab Transfer

The Tab Transfer window opens with three areas: Home (status and a Move rows button), Setup (rules, behaviour, automation and email) and Activity (recent runs).

If the menu doesn't appear right after installing, reload the spreadsheet tab.

3. Prepare your sheet

  • Headers go in row 1 of every tab you want to use. Tab Transfer reads row 1 as column names.
  • Use the same status column name (for example Status) on every tab that should be scanned.
  • Create the destination tabs first — for example Approved, Rejected, Archive.
  • Columns are matched by header name, not position, so destination tabs can have a different column order or extra columns of their own.

Tip: try your first setup on a copy of the spreadsheet (File → Make a copy) until you're happy with the result.

4. Set up your rules

In Setup → Rules:

  1. Status column — pick the header that holds the status.
  2. Statuses & destinations — add a rule for each status and choose the tab it should move to. To save typing, import the statuses:
    • Detect — reads the dropdown on the status column, or the values already used in it.
    • From selected range — select the cells that contain your statuses first.
    • From a dropdown cell — select one cell that has a dropdown.
  3. Watched tabs — exclude any tab that should never be scanned as a source (for example a dashboard or an archive).

Status matching ignores upper/lower case and surrounding spaces.

5. Choose how rows move

After a row moves

  • Delete the row (default) — the row is removed from the source tab.
  • Clear the row — the cells are emptied but the row stays in place.

Formatting of moved rows

  • Keep source formatting (default) — fill, font, colour, number format, alignment and wrapping travel with each cell.
  • Match destination — new rows take the look of the destination tab.
  • None — values only.

Timestamp

Optionally name a timestamp column. When a destination tab has a column with that header, Tab Transfer stamps the date and time each row arrived.

What happens to formulas

  • Formulas in the moved row arrive as their calculated values.
  • Per-row formulas already in the destination (for example =C2*D2 in every row) are extended to the new rows automatically.
  • Spilling formulas such as ARRAYFORMULA, QUERY or FILTER are left untouched.
  • Checkboxes and dropdowns keep their data validation; notes and links are preserved.

6. Automation

  • Instant — when someone changes a status, that row moves right away.
  • Scheduled — scan every 1, 2, 4, 6, 8 or 12 hours, or once a day at a chosen hour (in the spreadsheet's time zone).
  • Move rows now — from Home, run a batch on all tabs or just the current tab.

Click Save to apply the setup. Tab Transfer creates the needed triggers under the owner's account; turning an option off removes its trigger.

7. Email notifications

Turn on Email notifications and add one or more notifications. For each one choose:

  • When — rows land on a specific tab, or on any tab.
  • Mode — one email per row, or one digest per run listing every moved row.
  • Recipients — fixed addresses, and/or a column whose value is the address (for example Email). Add CC if needed.
  • Subject and message — use placeholders: any header as {{Header Name}}, plus {{From Tab}}, {{To Tab}}, {{Row Count}}, {{Moved At}}, {{Spreadsheet Name}} and {{Spreadsheet Link}}.

Under Sender & signature set a sender name, a reply-to address and your signature (copy it from Gmail settings and paste it in). Use Send test to email yourself a sample built from a real row.

Emails are sent from the owner's Google account and count toward Google's daily sending quota. If the quota runs out, remaining emails are skipped and the Activity log says so.

8. Owners & editors

  • The first person to save the setup becomes the owner. Only the owner can change the setup or run batch moves.
  • Editors change statuses as usual; the owner's trigger moves their rows and sends emails on the owner's behalf.
  • If the owner no longer has access to the spreadsheet, an editor can choose Take over from Home. The previous owner is notified by email.

9. Activity log

The Activity tab lists the 25 most recent runs: when they ran, what triggered them, how many rows moved to each tab, emails sent and any errors. It also shows which automatic triggers are active.

10. Troubleshooting

Rows aren't moving

  • Check that the status column header is spelled the same on each tab and is in row 1.
  • Check the status value matches a rule and the destination tab still exists.
  • Make sure the tab isn't excluded under Watched tabs.
  • Open Activity to see the last run and any error message.

"Only the automation owner can…"

Someone else saved the setup first. Ask the owner to make changes, or take over if they've left the file.

A column is empty in the destination

The destination has no column with that exact header name. Add a column with the same header.

Emails didn't arrive

Send a test email, check spam, check the recipient column contains valid addresses, and look for a quota message in Activity.

11. Turn off or uninstall

To stop automation in one spreadsheet, turn off Instant and Scheduled in Setup and save. To remove Tab Transfer completely, go to Extensions → Add-ons → Manage add-ons, open Tab Transfer's menu and choose Uninstall. You can also remove its access at myaccount.google.com/permissions.
